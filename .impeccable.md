# Design Context
Audience: Connor, using a personal pin collection app on a phone and laptop.
Use cases: photograph a pin, review possible matches, browse the catalog, save owned/wanted pins, open eBay sold listings.
Tone: familiar collector utility, similar to the reverse-engineered Pin Trading app at ../Documents/Playground/pinscanner-rea/runtime/signed-in.png. Charcoal surfaces, warm red accent, comfortable rounded controls, bottom navigation. Original branding: Pinfolio.
